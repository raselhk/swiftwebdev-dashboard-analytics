# SwiftWebDev Dashboard & Analytics

Free WordPress plugin by [Swift Web Dev](https://swiftwebdev.com/). Cookieless visitor stats, Google PageSpeed scores with Core Web Vitals, quick links, updates and site health in one modern admin dashboard.

- WordPress.org slug: `swiftwebdev-dashboard-analytics`
- Requires WordPress 6.5+, PHP 7.4+
- License: GPLv2 or later

See [readme.txt](readme.txt) for the full description and the external services this plugin uses.

## Releasing

Bump `Version` in `swiftwebdev-dashboard-analytics.php`, `SWIFTDASH_VERSION` and `Stable tag` in `readme.txt`, add a changelog entry, then push a tag with the same version number. The workflow publishes it to WordPress.org.
